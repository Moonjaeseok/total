☁️ 실시간 공유 데이터베이스(Firebase) 설정

GitHub + Cloudflare 환경에서 모든 접속자가 실시간으로 수정 내용을 공유하려면 Firebase 설정값을 입력해 주세요.

📌 설정 방법 요약

1. Firebase 콘솔에서 프로젝트 생성 ➔ 웹 앱(</>) 추가 후 firebaseConfig 복사

2. 좌측 메뉴 Firestore Database 생성 (규칙: allow read, write: if true; 설정)

3. 아래 입력창에 복사한 코드를 그대로 붙여넣고 [설정 내장된 index.html 다운로드]를 눌러 GitHub에 업로드하면 모든 사용자에게 즉시 자동 적용됩니다.
